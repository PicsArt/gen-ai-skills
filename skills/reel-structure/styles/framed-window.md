### Framed days

| Field | Value |
|---|---|
| Group | Cards and frames |
| Looks like | a white frame with the title above, each photo popping into the same window with its label, the last growing to full screen |
| Vibe | frame, window, gallery, clean |
| Fit | slots 4–8; photos; any; trip, Thanksgiving, Friendsgiving, any; warm, cosy |
| Music | warm acoustic pop, 95–105 BPM |
| Skin | the title is the skin's, in capitals; labels "DAY 1"… for a trip, the guests' names or the dishes for Thanksgiving; the page takes a light tint of the skin's background |
| Preview | https://gcdn.picsart.com/picsart-mcp/421fa488-60a8-4c64-9734-3b7c6c9ae8e4.mp4 |
| Proven | no |
| Seams | none; each photo pops into the same window (the template's own pop) |
| Motion | a slow zoom inside the window |
| Text | the title above the frame and a label below it, dark, held, both on the flat light page outside the frame, so they stay readable and off the faces in the photo |
| Look | none |
| Template | `scene://framed-window-slideshow`, `swapDuration` 0.6 and `expandDuration` 0.8 (the defaults pop too fast to read) |
| Ending | the last photo grows out of the frame to full screen |
| Skills | motion-design-craft, scene-template-remix |

- Format: framed slideshow with labels
- Length: 9 s
- Cut rate: ~50 changes/min (one photo every 1.2 s)
- Caption style: title above, a label under each photo
- Bed: acoustic pop, ~100 BPM
- Layout: single
