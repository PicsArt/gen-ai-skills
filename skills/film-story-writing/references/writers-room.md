# The writers' room

An optional way to write the story when it matters more than the time: several drafts written
apart, judged blind, and merged into one. In a bench of one episode, the merge scored 7.3 out of 10
against 4.3 to 6.7 for the single drafts it came from, and its animatic still lost the viewer: the
judges had read every line, so none of them could see what the picture left out. The room picks
the best story; only the cold watch says whether a stranger follows it. Offer it once, when the
user asks for drafts to choose from or says the story is the hard part; it costs nothing but time.

1. **Three drafts, written apart.** Each writer gets the same brief, the locked look and the
   user's fixed facts, and writes the ten lines and the scenes as `story.md` says. Where the host
   runs workers, each draft is its own worker and none sees another's. Otherwise write them one
   after another, each from the brief alone, and give each a different angle: whose story it is,
   where it starts, what the peak is.
2. **Judged blind.** Strip each draft of who wrote it and label it A, B, C. Judge each on the same
   lines, 1 to 10: does the first scene stop a viewer, does every decision have a cause we see,
   does each face feel one thing at a time, is it worth the viewer's time, is it filmable as
   written. Never "is it clear at first watch": a judge who read the draft can't tell. Where quality-review's critic panel runs, its story critic is
   one judge.
3. **One merge.** Take the best-scored draft as the spine and bring in the other drafts' best
   moments, each named with the line it fixes. The merge is one story, in one voice, held to the
   user's fixed facts, and it is checked like any story before it is shown.
4. **Show only the merge.** The user reads one story, with one line on what each draft gave it.
   The drafts stay in the record, never on a board.
