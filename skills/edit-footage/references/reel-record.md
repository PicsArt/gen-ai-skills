# The record, for the reel jobs

The record is `edit-footage.json`, kept as SKILL.md's The record says, with the edit-pipeline
skill's core keys. The reel jobs also keep:

- `job`: the job from `references/reel-jobs.md`, said back at step 1;
- `steps`, for a `lesson`: each product's stretch, in order of application, with the close-up that
  shows it;
- `brief`: `said`, `read` and `assumed`, kept apart, with the destination, the goal, the audience,
  the message, the length, the number of reels and the ending;
- `passes`: the agreed passes and which one you are on;
- `moments`: the picked ones, by source and range;
- `reframes`: per video, its saved reframe and its corrected file, as the footage-reframing skill says;
- `takes`: here the planned takes (clip lists), not a speaker's best take of a line, and for each
  reel the latest approved scene URL at each pass;
- `cut`: the cut the user chose or their words set (`clean`, `story`, `vibe` or `match`),
  as `references/reel-flow.md` says (Which cut);
- `style` and `stylesTried`, for a reel made in a style from the library: the style's id, and
  every style id built so far, so "Try another style" never builds one again;
- `openDecisions`.

A record from before the merge, `cut-footage-into-reel.json`, is the same project: continue it,
never restart it, and save it as `edit-footage.json`, as SKILL.md's The record says.
