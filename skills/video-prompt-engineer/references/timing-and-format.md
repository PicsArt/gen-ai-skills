# Timing and format

Retain the chosen duration and aspect ratio. Verify supported values in the exact provider/endpoint documentation before promising them. A prompt alone does not configure export settings; do not list invented portable duration or ratio options.

Compose for the intended crop. Keep necessary hands, feet, product edges and future caption space within the frame. Do not invent platform safe-zone measurements; use current official specifications when the task requires them.

Allocate action and camera phases within a known duration. When it is unknown and the edit is otherwise clear, use relative phases and note the assumption. For easing, pauses and blur, read [motion timing](craft-refinements.md#motion-timing).
