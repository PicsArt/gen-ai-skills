# Measure separate jobs

Choose one primary outcome for the experiment, with secondary diagnostics and a truth/brand guardrail. Use the metrics actually available in the account/interface; availability and definitions vary. Never invent retention, reach, sends, attribution or purchase data from public view counts.

| Job | Metric when available | Interpretation limits |
|---|---|---|
| Opening | Early retention/skip rate, with exact platform definition | Denominator and time threshold must be known |
| Continued viewing | Retention curve; average watch time; completion | Duration and repeat plays matter; average watch time / duration is not completion rate |
| Sharing | Sends / accounts reached, or shares / reach, labeled separately | Sends and all shares are not interchangeable |
| Utility | Saves / reach; useful questions | Saves do not establish buying intent |
| Buying interest | Qualified DMs, product visits, tagged link sessions | Define “qualified”; profile visits may not be attributable to one Reel |
| Commerce | Attributed orders/revenue, session conversion, acquisition cost if paid | Record attribution window/model, returns and unknown cross-device journeys |

Ratios require compatible numerator/denominator, source and time window. Do not mix plays with unique reach, paid with organic, or different observation ages. Mark zero denominators and missing data as unavailable, not zero performance. Repeated views can inflate viewing ratios beyond 100%.

## Pilot protocol

1. Record account, audience, objective, hypothesis, chosen primary metric and existing comparable baseline. Without a baseline, call the first set exploratory.
2. Compare meaningfully different opening treatments while keeping body, offer, duration and audience as similar as practical. If several variables change, call it a concept comparison, not an isolated hook effect.
3. For organic posts, posting time and audience allocation are uncontrolled. Use repeated comparable trials; Trial Reels may help explore non-follower response but are not randomized A/B tests. Check current availability before planning around them.
4. Set a comparable reporting window in advance (e.g. early diagnostic at 24h and a later 7-day read); these are practical defaults, not ranking windows. Let account volume determine the observation length. Do not declare a winner from a few views or a one-off outlier.
5. Report counts, ratios, sample size, spread across posts and confounds. No universal “good hook rate.” Use similar-length/account/category baselines and uncertainty. If evidence is too small or mixed, retain “inconclusive.”
6. Diagnose: early drop → opening relevance/clarity; drop before reveal → delay/confusion; strong watch but low shares → weak recipient value; strong watch but weak clicks → product/CTA/audience mismatch; visits without orders → inspect offer/fit/purchase path. These are hypotheses to investigate, not automatic causal verdicts.
7. Keep, revise or retire the mechanism with reasons. Track product-qualified outcomes alongside reach so a broad spectacle does not displace a commercially useful Reel.

Experiment record: concept ID/version; SKU; mechanism; first shot/line; body/offer changes; post URL/date; organic/paid; duration; reach/views; metric definitions; watch/completion if available; sends/shares/saves; qualified actions; attributed commerce; observation window; result/confidence; next test.
